## 正式数量表：一行一个可对应BOM的产品族/配置

| 字段 | 填写规则 |
|---|---|
| ID、年度、季度 | 自然年；财年数据先转期间，不按年份名称平移 |
| 企业集团、品牌、制造商 | 分开记录；子公司和并购前后品牌做别名映射 |
| 产品族、配置版本 | 能对应BOM；同一代型号有不同芯片时拆行 |
| 用途与协议 | DC前端/AI后端/管理网等；未知用途单列，不能硬分 |
| 销售路径、计数主体 | 品牌对外供货，或ODM直供；代工交品牌行只作核验 |
| 原始观测、单位、期间 | 台/数据端口/收入；标明出货、生产、订单或累计 |
| 同期台数：低/基准/高 | 有依据才填写；没有支持的中值不自动取区间平均 |
| 数量取得方式 | 企业披露/亲历访谈/收入÷匹配净ASP；说明转换 |
| 数据中心筛选与去重依据 | 产品用途证据、客户项目匿名ID、ODM与品牌对应关系 |
| 芯片型号及每配置颗数 | 主交换、线卡、fabric分列；集成SerDes不另算一颗 |
| Merchant/captive | 外购对外销售/内部自用；以实际交易关系判定 |
| 两份证据及独立性 | 原始文件页码或访谈编号；同报告的转述只能算一份 |
| 纳入状态与缺口 | 已验证/有依据估计/待验证/排除；排除也保留记录 |

**建议去重键：年度/季度＋归属集团/品牌＋匿名产品项目＋配置＋销售路径。** 键只能帮助查重；跨季度库存、品牌改名和同一项目代工转售仍要人工核对。再建立“ODM供货项目→品牌产品族→最终统计行”的对照表。

## 芯片价格与年度调整表

按“芯片型号/代际×年度×采购量级”记录净ASP区间、币种/汇率、折扣与返利、来源及与数量的匹配。另记芯片至整机计数节点的库存净变化、备件/损耗、收入确认差异。库存没有证据时保持未知，分别展示“整机隐含芯片装机量”和“芯片供应商销售估计”。

## 三项汇总检查

1. **可汇总样本：** 只加范围匹配、去重完成的记录；部分样本之和不得命名为全球市场。
2. **已识别缺口：** 逐家列未解决厂商/产品和有依据的范围；没有边界就写未知，不写任意尾部百分比。
3. **证据完整度：** 可以披露合格记录占本项目已估样本的比例；分母不是已知全球总量，不得改称真实市场覆盖率。
