# 辅助校验：架构、电力与其他产品

[返回主方法](06_market_sizing.md) · [架构教学Excel](../models/README.md)

本章保留原方案中有用的工程计算，但不再将全球服务器出货作为基础输入。**只有在某客户/项目的端点规模和网络配置有独立证据时，才用架构法校验供应商出货。** 它不负责填补所有未知厂商，也不能把供应商数量反推端点后再称为独立互证。

## 1. 已知集群怎样转换成交换机

先确定服务器/计算域数量、每台各张物理网络的连接数、速率、多平面和是否复用旧网络。年度服务器出货一般已包含替换，不能再叠加“存量÷寿命”；GPU数也不等于网卡端口数。

以两层leaf–spine为例：

```text
端点连接 E = 设备数 × 每设备在该平面的连接数
Leaf数 L = 向上取整(E / 每Leaf下联端口d)
层间链路 F = L × 每Leaf上联端口u
Spine数容量下限 = 向上取整(F / 每Spine可用端口p)
交换机侧已用端口 = E + 2F
物理链路 = E + F
```

Spine容量下限仍需通过实际连接图验证：端口、每对设备链路数、超售与容错均满足才成立。三层、多平面、breakout应重新建配置。前后端共用物理设备只计一次；800G拆成两个400G平面也不能再把原带宽乘二。

### 纯教学算例

2,048个端点、每端点一条800G、一平面；Leaf有32下联和32上联，Spine64口，每个Leaf连所有32台Spine。

| 输出 | 算式 | 数量 |
|---|---|---:|
| Leaf | 2,048÷32 | 64台 |
| Spine | 64×32÷64 | 32台 |
| 交换机 | 64+32 | 96台 |
| 主ASIC，假设每台一颗 | 96×1 | 96颗 |
| 交换侧已用端口 | 2,048+2×2,048 | 6,144个 |
| 链路 | 2,048+2,048 | 4,096条 |
| 双端均为可插拔光的模块 | 4,096×2 | 8,192只 |
| 假设芯片4,000美元/颗的价值 | 96×4,000 | 384,000美元 |

以上数量、价格和一台一颗配置均是教学假设，不是市场调查。breakout、AOC、双口模块、CPO会改变器件数量。配套[旧Excel](../models/README.md)继续用于这个例子的教学，不是新版供应商主模型。

## 2. 电力怎样检查部署是否现实

```text
可用IT功率预算 ≈ 已可使用的设施MW ÷ 对应PUE
某类AI部署预算 = IT功率预算 × 该类部署的分配比例
可支持端点数 ≈ AI预算MW × 1,000 ÷ 每端点对应的全IT设计kW
```

若分母只含GPU，需另分配CPU、网络、存储等功率。检查已投运容量，不用远期规划MW当当年部署；旧设备退出和改造也会释放容量。电力限制终端部署和交期，与设备供货还隔着库存，不能直接否定当年厂商销量。用户的800VDC和散热笔记在这里发挥作用，详见[第05章](05_notes_bridge.md)。

## 3. 外部机构数据的正确位置

本仓库原有IDC/Dell’Oro数字保留作行业背景与事后校验。它们不进入独立底表的销量、份额、ASP或尾部补足公式。比较前先看定义：历史整机收入、季度收入、包含多个协议的后端预测并非同一对象；单季乘四也不是全年实际。

外部差额过大时，回查范围、供应商遗漏、统计节点及价格；有新证据才修正，不用“其他”强行填平。由于本次试点尚未形成独立总量，没有执行数值比对。[来源目录](09_sources.md)

## 4. 扩展到其他Marvell产品时，另建分母

| 模块 | 数量起点和BOM | 需要补齐的关键输入 |
|---|---|---|
| 光DSP | 模块供应商分速率/类型出货×独立DSP附着率×每模块颗数；用链路两端验证 | 模块出货去重、LPO/LRO/CPO、净价 |
| AEC DSP | AEC线缆供应商出货×每根实际DSP颗数 | 两端BOM、距离/速率、品牌代工重复 |
| PCIe交换 | 平台/计算域出货×每域交换芯片BOM | 平台采用量、协议与代际、净价 |
| CXL交换 | 内存池/相关平台出货×每池BOM | 实际部署、CPU与软件支持、认证 |
| DCI coherent DSP | 波长/通道或模块出货×设备两端BOM | 距离、保护、模块与系统口径 |
| Custom ASIC | 具体客户项目出货×每系统芯片量×净价 | 定点、爬坡、收入确认；NRE单列 |

数据不可得时同样保留缺口，不以一个固定比例乘公司或数据中心总收入。不同器件可在同一半导体供应商收入层汇总；已包含它们的模块/整机收入不能再相加。CPO等一体封装对外总价只算一次。
