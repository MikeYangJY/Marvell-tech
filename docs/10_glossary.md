# 常用术语速查

[返回学习地图](../README.md)

| 术语 | 中文解释 | 在测算中的提醒 |
|---|---|---|
| ASIC | 专用集成电路 | 通用销售的交换ASIC也叫ASIC，不必然是Custom ASIC |
| Merchant silicon | 对外销售给多个客户的商用芯片 | 统计真实外部销售额 |
| Captive silicon | 企业内部系统自用芯片 | 不一定有可观察外部售价 |
| Fabless | 以设计为主、委外制造 | 不用晶圆厂收入代表芯片设计商收入 |
| OEM | 品牌设备厂 | 整机层 |
| ODM | 按客户方案设计制造设备的厂商 | 注意与品牌厂同一设备重复统计 |
| XPU | GPU及其他加速器的统称 | 不同架构每颗连接数不同 |
| NIC / SuperNIC | 网络接口卡／面向特定网络任务优化的网卡 | 卡、芯片和端口不是同一数量 |
| DPU | 卸载网络、安全、存储等基础设施任务的处理器 | 不等于GPU或交换ASIC |
| Scale-up | 扩大紧耦合计算域 | 按协议和系统BOM算 |
| Scale-out | 连接更多计算节点／域 | 常用后端fabric模型 |
| Scale-across / DCI | 跨数据中心互连 | 按距离、站点与链路算 |
| Fabric | 一套协同工作的互连网络 | 物理fabric是去重基础 |
| Leaf / spine | 接服务器的叶层／连接叶层的脊层 | 分层数设备 |
| ToR / EoR | 机柜顶部／行末交换部署位置 | 位置不等于额外拓扑层 |
| Radix | 交换器件可支持的连接基数 | 必须与单端口速率一起读 |
| Lane | 串行通道 | 多lane可组成一口；PCIe lane不同于以太网端口 |
| SerDes | 串并转换的高速接口电路 | lane速率不等于整机端口速率 |
| Oversubscription | 下行汇总带宽超过上行 | 2:1应明确分子分母 |
| RDMA / RoCE | 远程直接内存访问／基于以太网的相关实现 | 性能依赖端到端协议和拥塞管理 |
| ECN / PFC | 拥塞标记／基于优先级的流控 | 是控制机制，不是额外市场品类 |
| UEC / UET | Ultra Ethernet组织／传输方案 | 标准、芯片支持和量产要分开 |
| NVLink / NVSwitch | NVIDIA互连协议／交换器件 | 不当作以太网merchant ASIC计入 |
| PCIe | 处理器与外设等之间的高速互连标准 | switch和retimer是两类器件 |
| CXL | 基于PCIe物理层的缓存一致性/内存互连协议体系 | 看CPU及软件支持、内存池用途 |
| DSP | 数字信号处理器 | 光DSP是模块内芯片层 |
| Retimer | 恢复高速信号时序的器件 | 无需假设有交换转发功能 |
| DAC / AEC / AOC | 被动铜缆／有源电缆／有源光缆 | 每条链路的器件BOM不同 |
| PAM4 | 四电平脉冲幅度调制 | 属信号方式，不是网络协议 |
| CPO / LPO | 共封装光学／线性可插拔光模块 | 可能改变独立DSP价值与统计层级 |
| SONiC / SAI / SDK | 网络操作系统／交换抽象接口／软件开发工具包 | 软件兼容与认证影响切换成本 |
| BOM | 物料清单 | 从系统数量映射到器件数量的桥 |
| ASP | 平均销售价格 | 写明芯片或整机、净价或目录价 |
| TAM / SAM | 总可寻址市场／可服务市场 | 本项目须声明是否仅merchant |
| SOM | 可争取的市场／收入 | 需要项目与客户证据，不能当技术SAM |
| PUE | 总设施能耗÷IT能耗 | 规划容量换算仅为校准后的近似 |
| TDP | 热设计功耗 | 不能当作每GPU全部IT功耗 |
| CDU / DLC | 冷却分配单元／直接到芯片液冷 | 解释热转移，不直接决定端口量 |
| 800G / 800VDC | 通信速率／直流电压 | 无直接换算关系 |

术语按本手册用途简化。产品和协议细节可查[产品章节](02_products.md)及其官方来源。
